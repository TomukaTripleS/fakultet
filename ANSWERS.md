Окреме поле в базі не потрібне: статус обчислюється порівнянням дедлайну з поточною датою. У день дедлайну прийом ще триває. Збережений у базі статус міг би застаріти.

3.
0001_initial — видаляє таблицю програм обміну з усіма її записами.
0002_populate_exchange — видаляє записи з ID 1–6, зокрема внесені до них зміни.
0003_add_country — видаляє поле країни. Для початкових записів зворотна 0004 перед цим повертає країну в назву університету; для інших записів можливі втрати.
0004_split_university_country — точно відновлює початкові шість записів, але не гарантує відновлення довільних змінених або нових даних.
0005_normalize_places — відновлює початкові текстові значення для заданих університетів. Для довільних даних початкове формулювання не зберігається.
0006_places_integer — повертає числа в текстовий формат без втрати числових значень.
